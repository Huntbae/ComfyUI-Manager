# 네이버 블로그 자동 글쓰기 — "다음" 워크플로 (Claude Code 운영 지시서)

이 폴더는 클랜헌트 자료 폴더의 파일을 매일 한 편씩 네이버 블로그 초안(임시저장)으로
올리는 자동화다. 사용자가 **"다음"** 이라고 말하면 아래 절차를 **정확히 순서대로** 수행한다.

## 사전 설정 (최초 1회)

- `config.json`의 `sourceDir`가 실제 클랜헌트 폴더의 절대경로인지 확인한다.
  플레이스홀더("여기에_...")면 사용자에게 폴더 경로를 물어 채운다.
- `blogId`는 네이버 블로그 주소 `blog.naver.com/OOOO`의 `OOOO` 부분. (기본값: edukart)
- NID 쿠키가 저장돼 있어야 한다. 없으면 `node index.js cookies`를 먼저 안내한다.

## "다음" 을 받으면 실행할 절차

1. **다음 자료 확인**: `node scripts/next-source.js` 를 실행한다.
   - `ok:false` → 이유(no_config/dir_not_found)를 사용자에게 알리고 멈춘다.
   - `done:true` → "모든 자료를 게시했습니다"라고 알리고 멈춘다.
   - 정상이면 결과 JSON의 `file`, `text`, `images`, `sourceDir`, `blogId`, `remaining`을 얻는다.

2. **블로그 글 작성**: `text`(자료 원문)를 바탕으로 네이버 블로그용 글을 작성해
   이 폴더의 `content.txt`에 저장한다.
   - 첫 줄 = 제목, 그 다음 줄부터 = 본문.
   - 자료가 이미 완성된 글이면 자연스럽게 다듬는 정도로, 메모/자료면 블로그 글로
     재구성한다. 한국어 블로그 톤(친근한 존댓말), 문단을 적절히 나눈다.
   - **이미지 문맥 배치**: `images` 목록에서 글 내용과 어울리는 사진을 골라,
     본문에서 그 사진이 어울리는 위치의 **빈 줄에** `[[img:파일명]]` 형태로 넣는다.
     예) 요리 과정 문단 뒤에 `[[img:step2.jpg]]`. 파일명은 `images`에 있는 것만 쓴다.
     어울리는 이미지가 없으면 넣지 않아도 된다. 한 편에 1~3장이 적당.

3. **초안 게시(임시저장)**: 아래를 실행한다. (title은 content.txt 첫 줄과 동일하게)
   ```
   node index.js post --blog <blogId> --title "<제목>" --file content.txt --imagedir "<sourceDir>" --no-record
   ```
   - `imagedir`는 next-source의 `sourceDir`를 그대로 넣는다 (이미지가 그 폴더에 있으므로).
   - 결과가 `{"ok":true,"saved":true}` 면 성공. 실패면 reason을 사용자에게 알린다.
     (cookie_expired → 재로그인 후 `node index.js cookies`, no_cookies → 쿠키 저장 안내)

4. **진행 기록**: 게시 성공했을 때만 `node scripts/mark-done.js "<file>"` 를 실행한다.
   (`<file>`은 1단계의 자료 파일명. 이래야 다음 "다음"에서 그 편을 건너뛴다.)

5. **보고**: "오늘의 글 「제목」 임시저장 완료. 남은 자료 N편." 처럼 한 줄로 알린다.
   네이버 블로그 [글쓰기 → 저장된 글]에서 검토 후 발행하라고 덧붙인다.

## 규칙

- **하루 한 편만.** "다음" 한 번에 한 편만 게시한다 (자동 반복 금지 — 계정 보호).
- **발행 금지.** 항상 임시저장까지만. 발행 버튼은 사람이 검토 후 누른다.
- 게시에 실패하면 mark-done을 하지 않는다 (다음에 재시도되도록).
- `content.txt`는 매번 덮어써도 된다 (직전 편은 이미 네이버에 임시저장됨).
