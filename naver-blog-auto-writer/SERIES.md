# 시리즈 v5 — 검색 수요 기반 재편 (전 30편)

블로그 실제 게시글과 네이버 데이터랩 수요를 측정해 다시 짰다.

## 왜 다시 짰나 — 측정 결과

`blog.naver.com/huntbae` 게시글을 네이버 검색 API로 조회하고,
데이터랩으로 12개월 검색 수요를 쟀다 (2025-09 ~ 2026-09, 월별 지수).

| 키워드군 | 지수 범위 | 판단 |
|---|---:|---|
| 체험·나들이 (아이와 갈만한 곳 / 실내 체험 / 주말 나들이) | 45~100 | **최상** (3월 100) |
| **면허·법규** (원동기 면허 / 저속전기차) | 42~100 | **최상** (1월 100) — 그동안 한 편도 안 씀 |
| 전동카트·골프카트·전기카트 | 60~88 | 높음 (3~6월 피크) |
| 체험학습·방과후·자유학기제 | 10~28 | 중간 |
| 구매검토 (전동카트 가격/추천) | 0.8~3 | 낮음 |
| 에듀카트·코딩교육·메이커교육 | 0.5~7 | 낮음, 하락 중 |
| 고장·정비 (전동카트 배터리/카트 수리) | 0.02~0.04 | **사실상 0** |
| **사이클카트·뉴트로엠·칼리 전기차** | **집계 없음** | **사실상 0** |

두 가지가 결정적이었다.

**하나 — 사이클카트·뉴트로엠은 검색량이 집계 최소치에도 못 미친다.**
v4 사이클카트 시리즈 25편은 내용은 정확하지만 아무도 찾지 않는 말로 쓰였다.
`articles_v4/` 에 보관했고, 필요하면 언제든 되돌릴 수 있다.

**둘 — 면허·법규 수요가 아주 크다.** 원동기 면허·저속전기차는 1월에 지수 100을 찍는다.
그런데 이 블로그에는 관련 글이 한 편도 없었다. 제품이 사륜형 이륜차로 분류되므로
이 검색을 하는 사람이 곧 잠재 고객이다. 가장 큰 빈자리였다.

## 법규 관련 — 단정하지 않는다

17~20편은 면허·법규를 다루지만 **"이 면허면 됩니다" 라고 단정하지 않는다.**
법령은 바뀌고, 잘못 안내하면 그 부담은 산 사람에게 간다.

- 제품 분류(사륜형 이륜차)는 자사 표기 그대로 쓴다
- 면허 요건·등록 의무·도로 주행 가능 여부는 **관할 기관 확인을 함께 안내**한다
- 확인되지 않은 것은 확인되지 않았다고 적는다

**⚠ 사용자 확인 필요:** 사륜형 이륜차 분류와 원동기 면허 관련 서술은
자사 블로그 해시태그와 2023년 배포 원고에서 확인한 것이다.
현재 기준이 맞는지 한 번 확인하고 게시하는 것을 권한다.

## 쓰지 않은 숫자

가격, 주행거리, 충전시간, 배터리 수명, A/S 조건, "매출 N% 증가" 류.
확정된 근거가 없어 쓰지 않았다. 본문에도 못 드리는 이유를 적었다.

## 근거가 있어 쓴 것

**제품** — 에듀카트: 아두이노 메가 / BTS7960 / MY1020Z / LiFePO4 25.6V 16.5Ah /
전용 PCB / 10~14km/h. V2: 24V 체인 구동, 자작나무 프레임. V4 존재.
칼리: 전기구동, 1950년대 형태(둥근 보닛·크롬 그릴·원형 헤드램프), NewtroM = New Retro Mobility,
사륜형 이륜차 분류. 라인업: 칼리·달리·RC·RK·마실카.

**도입 실적** (자사 블로그 게시글에서 확인) — 군산기계공업고등학교(2023~2024, 5차례),
전북인력개발원, 경주 코오롱 호텔 에듀캠프(2024), 오남고 V4 2대,
용산 어린이공원 에듀테크 체험마당.

## 블로그 점검에서 발견한 문제

1. **중복 게시** — 「100년 전 그들도 직접 만들었다」가 2026-07-29와 2026-08-03에 같은 내용으로 두 번 올라가 있다.

   사이클카트는 1995년 미국에서 시작됐다 (v4 시리즈 참고).
3. **블로그 분산** — `huntbae` 와 `edukart` 두 곳으로 나뉘어 있다.
4. **2023-12-21 배포 원고** — 타 블로그 10곳 이상에 거의 동일한 문구가 같은 날 올라가 있다.
   검색엔진이 중복 문서로 볼 수 있다.

## 확인된 사실만 쓴다 — 근거 목록

**사이클카트**
- 1995년 캘리포니아 델마에서 피터·마이클 스티븐슨 형제가 첫 대 제작
- 2002년 4월 Road & Track에 「Stevenson Type 59 Cyclekart」 "At a Glance" 스펙 게재 — 이 부류 최초의 공개 수치, '스티븐슨 포뮬러'의 기준
- 규격: 3인치 각파이프 메인레일 + 크로스 브레이싱 / 4행정 단기통 / 기본 고카트 조향·제동
- 휠: 혼다 17×1.75 또는 17×2인치 림, 17×2.50 타이어
- 트랙 38인치 / 휠베이스 약 66인치 / 최대 중량 250파운드 / 200cc급 6.5마력 (Honda GX200, Predator 212)
- 피터 스티븐슨: Road & Track 기고자, 『The Greatest Days Of Racing』 저자(서문 필 힐), 2012년 6월 별세

   `.auth/history-credits.json` 과 `images/CREDITS_history.md` 에 기록한다
5. 원고의 캡션을 `설명 / 사진: 저작자, 라이선스 (Wikimedia Commons)` 로 바꾼다

설명은 Commons의 **파일명**에서 뽑는다. `ImageDescription` 은 프랑스 국립도서관 목록
메타데이터(`Sujet : Cyclecars -- France Courses automobiles -- ...`)인 경우가 많아 본문에 쓰기 나쁘다.
캡션은 실행할 때마다 다시 계산하므로, 표기 규칙을 고치면 `kart history` 재실행만으로 전편에 반영된다
(이미 받아둔 사진은 다시 내려받지 않는다).

**Commons의 `Category:Cyclekart` 에는 파일이 4장뿐이고 그중 3장이 같은 차(Fiat S76 복제)의
각도만 다른 컷이다.** 그래서 사이클카트 슬롯은 2장만 쓰고 나머지 자리는 자사 사진으로 채웠다.
같은 피사체가 여러 편에 반복되지 않게 하기 위해서다.

출처가 채워지기 전에는 `node index.js next` 가 **거부한다**.
원고에 `(출처 확인 전 …)` 문구가 남아 있으면 게시가 막힌다 — 남의 사진 무단 게시 방지 장치다.

원고 본문은 특정 사진의 내용을 콕 집어 설명하지 않는다. 어떤 사진이 배정돼도 글이 안 어긋나게 썼다.

## 매일 하나씩 자동 업로드

```
kart daily            # 매일 09:00 등록
kart daily 21 30      # 매일 21:30
kart daily status     # 상태 + 최근 로그
kart daily run        # 지금 한 번
kart daily off        # 끄기
```

macOS launchd(LaunchAgent) 에 `com.clanhunts.blog.daily` 로 등록된다.
매일 `scripts/daily.sh` 가 `git pull → 역사 사진 확보 → node index.js next → 오래된 로그 정리` 순으로 돈다.
로그: `out/logs/daily-<날짜>.log`.

**발행은 여전히 사람이 한다.** 자동화는 임시저장까지만이다.
맥 전원이 꺼져 있던 날은 건너뛰고, 그 글이 다음 날 대상이 된다. 실패해도 진행 기록을 남기지 않아 재시도된다.

### 카드뉴스가 아니라 사진으로

카드뉴스(글자가 얹힌 디자인물)를 본문에 넣으면 광고처럼 보인다. 두 가지로 막는다.

- 수집 단계에서 `카드뉴스`·`상세페이지`·`표지`·`시안` 등을 제외 목록에 넣었다.
- 그래도 카드가 들어오면 **안에 박힌 사진만 잘라낸다.** 배경이 단색이고 글자 줄은
  배경과 다른 픽셀 비율이 낮다는 성질로 사진 영역을 찾는다. 일반 사진은 건드리지 않고,
  사진이 아예 없는 CTA 카드는 후보에서 뺀다.

```
python3 scripts/rebuild_images.py --dry-run        # 계획만 확인
python3 scripts/rebuild_images.py                  # 구글 드라이브에서 수집
python3 scripts/rebuild_images.py --no-sweep       # 제품 사진만 (전체 훑기 끔)
python3 scripts/rebuild_images.py --from-existing  # 드라이브 없이 기존 사진으로 (임시)
python3 scripts/rebuild_images.py --src ~/어떤폴더    # 검색 폴더 직접 추가
```

### 어디서 찾나

한 곳만 보지 않는다. 실행하면 검색할 폴더 목록을 먼저 출력한다.

| 대상 | 경로 |
|---|---|
| 내 드라이브 | `~/Library/CloudStorage/GoogleDrive-*/내 드라이브` |
| 공유 드라이브 | `.../공유 드라이브` (또는 `Shared drives`) |
| 공유 문서함 | `.../공유 문서함` (또는 `Shared with me`) |
| 로컬 작업폴더 | `~/Work Files`, `~/Documents/Work Files` 등 |
| 직접 지정 | `--src <경로>` (여러 번 사용 가능) |

계정이 여러 개면 계정마다 세 갈래를 모두 본다. 한글·영문 폴더명 둘 다 인식한다.
`내 드라이브/Work Files/클랜헌트` 처럼 드라이브 안에 있는 작업폴더는 내 드라이브를 돌 때 함께 잡힌다.

### 사진을 찾는 3단계

제품 사진이 모자랄 때 단계적으로 범위를 넓힌다. 앞 단계로 채워지면 다음 단계는 실행하지 않는다.

| 단계 | 범위 | 예 |
|---|---|---|
| 1단계 정밀 | 파일명·폴더명이 제품과 직접 맞는 것 | `에듀카트 v4.jpg`, `개발 차량 이미지/` |
| 2단계 확장 | 활동·부품 키워드 | `안전정비 교육`, `조립 워크숍`, `시승 체험` |
| 3단계 전체 | 드라이브 전체 사진 중 품질 통과분 | 최근 파일부터, 가로 800px·120KB 이상 |

모든 단계에서 공통으로 걸러내는 것:

- **서류·행정** — 실측확인서, 제원표, 견적, 계약, 공고, 입찰, 증빙, 정산
- **판촉물·화면** — QR코드, 현수막, 배너, 포스터, 명함, 스크린샷, 로고
- **개인정보** — 주민·여권·신분증·통장·이력서·서명·도장 등이 이름에 든 파일
- **상대 제품** — 에듀카트 자리에 칼리 사진이 들어가지 않게 서로 막는다
- **품질 미달** — 아이콘·썸네일·극단적 가로세로비

3단계로 뽑힌 사진이 있으면 실행할 때 목록과 함께 경고가 뜬다.
제품과 무관한 사진일 수 있으니 반드시 확인하고, 원치 않으면 `--no-sweep`을 쓴다.

`--from-existing`은 원본 사진이 모자라 같은 사진이 다른 스타일로 반복된다. 임시 방편이다.
제대로 하려면 드라이브 수집을 쓰고, eDu Kart Ver.5 사진은 `images_src/edukart_v5/`에 넣는다.

**`images_master/` 는 손대지 않은 원본이다.** `--from-existing` 은 여기서만 읽는다.
생성된 `images/` 를 다시 원본으로 쓰면 크롭·보정이 누적돼 사진이 점점 확대된다.
(실제로 한 번 겪었다 — 프레임 일부만 크게 잡힌 사진이 나왔다.)

`node index.js next`는 실행 전에 사진 존재를 확인한다. 하나라도 없으면
사진 없이 글만 올라가는 것을 막고 멈춘다.

## 41~50편 — 전기차 (일반 독자)

네이버 데이터랩에서 세 번째 주제를 골랐다.

| 주제군 | 지수 범위 |
|---|---|
| **전기차 · 전기차 보조금 · 충전 · 추천** | **36~100** |
| 시니어 이동수단(전동휠체어·실버카 등) | 5~11 |
| 진로체험 · 자유학기제 | 0.9~2.6 |
| 코딩·로봇·AI 교육 | 1.3~2.3 |

검색량이 가장 큰 주제지만 그대로 쓰면 위험하다. 보조금 금액·충전 요금·차종 비교는
확인할 수 없기 때문이다. 그래서 각도를 **"작은 전기차를 직접 만들어본 사람이 보는 전기차"**
로 잡고, 물리·구조 수준의 일반 지식과 자사 경험만 쓴다.

| 편 | 다루는 것 |
|---|---|
| 41 | 시리즈 선언 — 만들어보면 다른 게 보인다 |
| 42 | 왜 조용한가 — 폭발이 없으면 소리도 없다 |
| 43 | 회생제동 — 모터를 거꾸로 쓰면 발전기 |
| 44 | 100%까지 충전하지 말라는 이유 |
| 45 | 부품이 적은 이유 — 사라진 것과 새로 생긴 것 |
| 46 | 정비 항목이 어떻게 갈리나 |
| 47 | 완속과 급속 — 변환을 어디서 하느냐 |
| 48 | 없앤 소리를 다시 만들어 넣는 이유 |
| 49 | 자주 듣는 말들 하나씩 따져보기 |
| 50 | 작은 전기차가 알려주는 것들 |

**쓰지 않은 것**: 보조금 금액, 충전 요금, 특정 차종 비교, 실차 주행거리 수치.
41편에 '보조금'이라는 단어가 두 번 나오는데, 둘 다 "그런 이야기는 하지 않는다"는 문맥이다.
