# 03. Xmind 기능·디자인 분석

> **조사 방법 한계 명시**: 조사 환경의 네트워크 정책상 `xmind.com` / `xmind.net` 직접 접근이
> 차단되어, **공식 사이트 원문 대신 검색 결과 요약, 사용자 가이드 인용, 서드파티 리뷰(2026년 기준),
> 그리고 공식 SDK 소스코드**를 근거로 재구성했다.
> 픽셀 단위 디자인 분석(정확한 색상값·간격·타이포)은 **실제 앱을 설치해 직접 측정하는 단계가 별도로 필요**하다.

---

## 1. 기능 인벤토리

### 1.1 다이어그램 구조 (Structure)

Xmind는 **하나의 맵 안에서 서브트리마다 다른 구조를 섞어 쓸 수 있다.** 이것이 경쟁 제품과의 차별점이자,
`structureClass`가 루트뿐 아니라 개별 토픽에도 붙는 이유다.

- 마인드맵 (균형/비균형)
- 논리 구조도 (좌/우)
- 조직도 (상/하)
- 트리 / 디렉터리
- 타임라인 (수평/수직)
- 피시본 (좌향/우향)
- 매트릭스 (스프레드시트)

### 1.2 뷰 모드 — Xmind의 핵심 UX 자산

| 모드 | 설명 | 우리 우선순위 |
|---|---|---|
| **Map** | 기본 시각 편집 | Must |
| **Outliner** | 클릭 한 번으로 맵 ↔ 계층 목록 전환. 아젠다·태스크 리스트로 바로 전환 | **Should** — 구현 난이도 대비 체감 가치가 매우 높다 |
| **Pitch** | 맵을 **자동으로 슬라이드 덱으로 변환**, 브랜치마다 1슬라이드 + 전환효과 | Could |
| **ZEN(집중) 모드** | 몰입 편집 | Could |

> **전략적 관찰**: Outliner는 "같은 데이터의 다른 뷰"일 뿐이라 **데이터 모델만 제대로 잡으면 거의 공짜**다.
> 반면 사용자가 느끼는 가치는 크다. **가성비 1위 기능.**

### 1.3 노드 요소

텍스트 · 리치텍스트 · 이미지 · 아이콘/마커 · 노트 · 첨부파일 · 라벨(태그) · 하이퍼링크 ·
요약(Summary) · 관계선(Relationship) · 경계선(Boundary) · 말풍선(Callout) ·
플로팅 토픽 · 체크박스/할일 · 자동 넘버링 · 수식(LaTeX)

### 1.4 스타일링

- 100종+ 테마, 커스텀 테마 (Pro)
- 브랜치 색상 자동 배분(rainbow), 선 두께/곡률, 노드 도형
- 손그림(hand-drawn) 스타일 — Xmind의 시그니처 룩

### 1.5 AI 기능 (2026 기준)

프롬프트/텍스트 → 맵, 문서·PDF 요약, 웹페이지·링크 요약, 영상 요약, 이미지 → 맵,
아이디어 확장, 설명, 재구성, 맵 다듬기, 작업 분해(task breakdown), 피치 영상, AI 공동편집.

### 1.6 협업 / 유료 정책 (2026)

- Pro $10/월 (연간 $4.92/월), Premium $15/월 (연간 $8.25/월)
- Premium: 무제한 협업 맵, **실시간 협업**, AI 크레딧 500/월, 간트 차트, 태스크 내보내기
- Pro: 무제한 Pitch 슬라이드, 커스텀 테마

> **경쟁 분석 시사점**: Xmind의 유료 장벽은 **협업·AI·Pitch**에 걸려 있다.
> 반면 **"내 파일을 내 디스크에서 자유롭게 편집한다"**는 부분은 상대적으로 약하다.
> 로컬 우선(local-first) + 무손실 호환 + 오픈 포맷이 우리의 포지셔닝이 된다.

## 2. 우선순위 (MoSCoW)

### Must — 이게 없으면 제품이 아니다

- `.xmind` 열기 / **무손실 저장** (다중 시트 포함)
- 노드 CRUD, 텍스트 편집, 드래그 재배치, 접기/펼치기
- 실행취소/다시실행
- 구조 전환 (최소: 마인드맵, 논리도, 조직도, 트리)
- 노트, 라벨, 하이퍼링크, 이미지, 마커
- 요약 · 관계선 · 경계선 · 플로팅 토픽 (**보존 최소, 편집 목표**)
- 키보드 중심 조작 (Tab=자식, Enter=형제 — Xmind 사용자의 근육 기억)
- PNG / PDF / Markdown 내보내기

### Should

- **아웃라이너 뷰**
- 테마 적용 및 보존, 브랜치 색상
- 검색 / 필터 (라벨·마커 기준)
- 타임라인 · 피시본 · 매트릭스 구조
- 자동 저장 및 로컬 히스토리
- Markdown / FreeMind / OPML import

### Could

- Pitch(슬라이드) 모드
- 손그림 스타일
- 수식, 자동 넘버링
- AI 보조 (프롬프트 → 맵, 브랜치 확장)
- ZEN 모드

### Won't (v1 범위 밖)

- 실시간 협업 (Phase 4로 분리)
- 간트 차트 / 프로젝트 관리
- 모바일 네이티브 앱
- Xmind 클라우드 계정 연동

## 3. UX / 디자인 방향

### 3.1 반드시 지켜야 할 상호작용 규약

기존 Xmind 사용자를 데려오는 것이 목표라면, **키맵을 바꾸면 안 된다.**

| 동작 | 키 |
|---|---|
| 자식 토픽 | `Tab` |
| 형제 토픽 | `Enter` |
| 편집 진입 | `Space` / `F2` / 더블클릭 |
| 노트 | `Ctrl/Cmd + Shift + N` 계열 |
| 접기/펼치기 | 노드 호버 시 나타나는 원형 토글 |
| 캔버스 이동 | 스페이스 드래그 / 휠 / 트랙패드 팬 |
| 줌 | `Ctrl/Cmd + 휠` |

### 3.2 화면 레이아웃 (Xmind 계열의 표준형)

```
┌──────────────────────────────────────────────┬──────────┐
│ 상단: 파일/뷰 전환(Map·Outline·Pitch)/공유    │          │
├────┬─────────────────────────────────────────┤ 우측     │
│ 좌 │                                         │ 패널     │
│ 사 │            무한 캔버스                   │ (스타일/ │
│ 이 │         (중심 토픽 = 시각 앵커)          │  노트/   │
│ 드 │                                         │  아웃라인)│
│    │                                         │          │
├────┴─────────────────────────────────────────┴──────────┤
│ 하단: 시트 탭 · 줌 컨트롤 · 미니맵                        │
└──────────────────────────────────────────────────────────┘
```

- **우측 패널은 컨텍스트 의존적**이어야 한다(선택된 것이 노드면 노드 스타일, 캔버스면 테마).
- 시트 탭은 하단 — 다중 시트 지원이 Must이므로 v1부터 자리를 비워두지 말 것.

### 3.3 디자인 원칙

1. **캔버스가 주인공** — 크롬(툴바/패널)은 필요할 때만 나타난다.
2. **선택 상태가 항상 명확** — 다중 선택·범위 선택 피드백이 편집 속도를 좌우한다.
3. **애니메이션은 레이아웃 변화에만** — 노드 추가/삭제/구조 전환 시 위치 트윈.
   이게 없으면 맵이 "튀어서" 사용자가 맥락을 잃는다.
4. **다크 모드 필수** — 테마 색상과 UI 색상을 분리 설계해야 나중에 고생하지 않는다.

### 3.4 ⚠️ 디자인 모방의 경계선

"xmind.net과 동일한 앱"이라는 목표는 **기능 동등성**으로 해석해야 하며,
**시각적 트레이드드레스(로고·아이콘 세트·고유 테마 그래픽·마커 아이콘 이미지)를 그대로 복제하면 안 된다.**
자세한 내용은 [06번 문서](06-legal-risk.md) 참조.

- ✅ 허용: 파일 포맷 호환, 기능 구성, 키보드 단축키 관례, 일반적 레이아웃 패턴
- ❌ 금지: Xmind 로고/상표 사용, 아이콘·마커 이미지 에셋 복사, 테마 그래픽 리소스 추출 후 재배포

**마커는 특히 주의** — `markerId`(문자열)는 보존하되, **렌더링용 아이콘은 우리가 새로 그리거나
오픈 라이선스 아이콘 세트(예: Lucide, Phosphor)로 매핑**한다.
이러면 왕복 호환은 유지되면서 저작권 문제는 발생하지 않는다.
